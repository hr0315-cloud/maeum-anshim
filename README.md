# 마음안심

> 설명서·실행 방법·개인정보와 윤리 설명은 제출 저장소 README에 있습니다: https://github.com/aihae2026/aihae_final27

사회복지사의 대면 상담 중 위험한 말을 감지해 사무실 동료에게 알리는 웹앱입니다. 파일은 `index.html`, `style.css`, `app.js`, `config.js` 네 개이고, 설치할 프로그램과 계정이 없습니다.

## 가져다 쓰기 전에 꼭 읽어 주세요

- **이 버전은 시연용입니다.** 실제 상담에는 아래 '알려진 한계'를 해결한 뒤에 쓰세요.
- **`config.js`에 기관의 서버 주소를 넣어야 합니다.** 기본값은 비어 있습니다.
  - `sttRelayUrl`: 음성인식 중계 서버 주소. 이 저장소에는 중계 서버가 들어 있지 않습니다. 비워 두면 받아쓰기는 브라우저 음성인식으로 동작하고, 음성은 브라우저 업체의 서버(크롬은 구글, 아이폰·아이패드는 애플)로 전송됩니다. 상대방 말이나 긴 문장의 정확도가 낮을 수 있습니다.
  - `ntfyServer`: 알림 중계(ntfy) 서버 주소. 비워 두면 동료 연결을 쓸 수 없습니다. 실제 상담에는 접근 제어(토큰)를 켠 기관 자체 ntfy 서버를 쓰세요. 공개 서버 `https://ntfy.sh`는 시연 전용입니다.
  - `topicPrefix`: 알림 채널 이름 앞에 붙는 글자. 기관 고유 값으로 바꾸세요.
- **팀 코드는 비밀번호입니다.** 앱의 '새 코드 만들기'로 만든 16글자 코드를 쓰고(직접 입력은 12글자 이상), 화면 공유·사진에 보이지 않게 합니다. 유출이 의심되면 새 코드를 만들어 모든 기기를 다시 연결합니다.
- **암호 문구는 기관마다 바꿉니다.** 기본값은 코드에 공개되어 있습니다(설정 화면 > 감지 목록).
- 시연·교육에는 가상 이름과 가상 장소만 씁니다.

## 알려진 한계

- 신호에 보낸 사람 서명이 없습니다. 팀 코드를 아는 사람은 가짜 '수락'·'확인했어요'·위험 신호를 보낼 수 있습니다.
- 신호 내용(상담자·동료 이름, 장소, 내담자 이름, 감지 구절과 앞뒤 30자)은 암호화되지 않은 채 ntfy 서버에 도착하고, 서버에 12시간 남습니다.
- 상담 기록·팀 코드·AI API 키는 브라우저 저장소(localStorage)에 암호화 없이 저장됩니다. 상담용 기기는 상담자 전용으로 쓰고 화면 잠금을 설정하며, 공용 PC에서는 쓰지 않습니다.
